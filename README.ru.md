# Bandcamp Collection Downloader (GUI)

Двуязычное (русский / английский) приложение для Windows, macOS и Linux,
которое скачивает **ваши собственные покупки** с Bandcamp: альбомы и отдельные
треки в выбранном формате.

Программа не ищет пиратские ссылки, не обходит оплату и не снимает DRM. Она
открывает официальные страницы повторного скачивания Bandcamp
(`/download?payment_id=…`), доступные только владельцу покупки, и сохраняет
файлы, которые Bandcamp сам предлагает скачать.

## Происхождение проекта и авторство

Это графическое приложение основано на оригинальном
[`bandcamp-downloader`](https://github.com/easlice/bandcamp-downloader)
Эндрю Слайса (Andrew Slice, 2022), распространяемом по лицензии MIT.

Этот GUI является частью
[моего форка](https://github.com/muesqtk/bandcamp-downloader).

Старый консольный скрипт `bandcamp-downloader.py` **удалён из этой
GUI-сборки**. Оригинальный консольный инструмент по-прежнему доступен в
исходном репозитории. GUI использует собственное ядро (`bc_core.py`) и
придерживается тех же правовых рамок: только контент, купленный вами на
Bandcamp.

## Возможности

* Загрузка всей коллекции Bandcamp или скрытых покупок.
* Поиск по исполнителю/названию, фильтр «Альбомы / Треки», режим «Только не
  скачанные».
* Выбор отдельных позиций, «Выбрать все» / «Снять все», переключение пробелом.
* Панель предпросмотра с обложкой, названием, датой покупки и доступными
  форматами.
* Форматы: **FLAC, ALAC, AIFF, WAV, MP3 320, MP3 V0, AAC-HI, Ogg Vorbis**,
  а также **Авто** (сначала лучший lossless).
* Параллельная загрузка (1–16 потоков), прогресс по каждой позиции и общий
  прогресс, скорость и затраченное время.
* Докачка с места обрыва (`.part` + HTTP `Range`), проверка размера файла.
* Повторы с нарастающей паузой при сетевых ошибках, HTTP 429 и 5xx.
* Пропуск уже скачанного, продолжение прерванной загрузки.
* Безопасная распаковка ZIP с защитой от `zip-slip`; опциональное удаление
  архива после успешной распаковки.
* Шаблон путей `{artist}/{album}` и другие поля.
* Прокси (HTTP/HTTPS/SOCKS), настраиваемое число попыток и пауза.
* Журнал с подробным режимом и сохранением в файл.
* Уведомление о завершении, открытие папки, сохранение настроек между
  запусками.
* Cookies читаются из браузера или вставляются вручную; **хранятся только в
  памяти и никогда не записываются на диск**.
* Мгновенное переключение русского/английского интерфейса в верхней панели.

## Требования

### Портативный исполняемый файл

Готовая сборка — один `.exe` для Windows, Python **не нужен**. Как собрать её
самостоятельно, см. в разделе
[Сборка Windows-исполняемого файла](#сборка-windows-исполняемого-файла).

### Запуск из исходников

* Python **3.10+** (рекомендуется 3.11–3.14).
* Tkinter — входит в стандартный установщик Python для Windows.
* Интернет и аккаунт Bandcamp, на котором куплены альбомы/треки.

Проверить Python:

```bat
python --version
```

Если команда не найдена, установите Python с python.org и включите
«Add Python to PATH» и компонент «tcl/tk and IDLE».

## Установка из исходников

Откройте командную строку в папке программы и выполните:

```bat
pip install -r requirements.txt
```

Или запустите `install.bat`.

Основные библиотеки:

| Пакет | Зачем |
|---|---|
| `curl_cffi` | HTTP с TLS-отпечатком браузера для надёжных запросов к Bandcamp |
| `requests` | резервный HTTP-клиент |
| `beautifulsoup4` | разбор страниц Bandcamp |
| `browser_cookie3` | чтение cookies входа из браузера |
| `Pillow` | обложки в панели предпросмотра |

Без `curl_cffi` программа запустится через `requests`, но Bandcamp чаще
показывает «Client Challenge» и HTTP 429.

## Запуск из исходников

* `run.bat` — обычный запуск без консольного окна.
* `run_console.bat` — запуск с консолью и сообщениями об ошибках (полезно при
  проблемах).
* Вручную:

```bat
python bandcamp_gui.py
```

Параметры командной строки:

```bat
python bandcamp_gui.py --version
```

## Язык интерфейса

Программа полностью переведена на русский и английский.

* Переключатель языка находится в правом верхнем углу. Язык меняется сразу,
  без перезапуска. Во время загрузки или проверки форматов переключение
  блокируется.
* При первом запуске язык определяется по языку интерфейса Windows. На других
  системах используется английский.
* Выбор сохраняется в `settings.json`.
* Переменная окружения `BCD_LANG=en` или `BCD_LANG=ru` принудительно задаёт
  язык на один запуск.
* Полная справка на русском и английском (включая авторство, лицензию и
  инструкции) доступна по кнопке **«Справка»**.

## Вход в Bandcamp

1. Войдите в свой аккаунт на [bandcamp.com](https://bandcamp.com/) в браузере
   (Chrome, Edge, Firefox, Brave, Opera и т. п.).
2. В верхней панели программы выберите браузер в поле **«Cookies из»**.
   «Авто» перебирает браузеры по очереди.
3. Укажите имя профиля — часть адреса после `bandcamp.com/`.
   Например, для `https://bandcamp.com/user` введите `user`.
4. Нажмите **«Загрузить коллекцию»**.

Если автоматическое чтение не сработало:

* нажмите **«Войти…»** → **«Импортировать cookies»** для выбранного браузера;
* либо вставьте cookies вручную и нажмите **«Применить»**. Поддерживаются:
  * заголовок `Cookie: name=value; …`;
  * файл Netscape `cookies.txt`;
  * JSON-словарь `{"name": "value", …}`;
  * кнопка **«Из файла…»**.

Нужна cookie `identity` (активная сессия Bandcamp). Cookies хранятся только в
оперативной памяти и не попадают в настройки или журнал.

## Как скачивать

1. Загрузите коллекцию.
2. Снимите галочки с ненужных позиций (столбец `✓`) или используйте поиск и
   фильтры, затем «Выбрать все» / «Снять все».
3. Выберите **формат**, **папку** и число **потоков**.
4. При необходимости откройте **«Дополнительно…»**: шаблон имён, прокси,
   попытки, пауза, уведомления, подробный журнал.
5. Нажмите **«Скачать выбранные»**.

Во время загрузки доступна кнопка **«Отмена»**: текущие файлы остаются в
`.part` и могут быть докачаны при следующем запуске.

Полезные действия:

* **Пробел** — поставить/снять галочку у выделенных строк.
* **Двойной клик** — открыть покупку на Bandcamp.
* **Правый клик** — контекстное меню: скачать, проверить форматы, открыть
  страницу, скопировать ссылку, выбрать/снять.
* **«Проверить форматы»** — заранее узнать, какие форматы доступны для
  выбранных покупок (по одному запросу на позицию; возможны ограничения
  Bandcamp).

## Форматы

Bandcamp отдаёт альбомы ZIP-архивом, а отдельные треки — аудиофайлом.

* Выбранный формат применяется к каждой покупке.
* Если формата нет, скачивается лучший доступный, а в журнал пишется
  предупреждение.
* «Авто» предпочитает lossless: FLAC → ALAC → AIFF → WAV → MP3 320 → AAC →
  Vorbis → MP3 V0.
* Расширения `.zip`, `.flac`, `.mp3`, `.m4a`, `.aiff`, `.wav`, `.ogg`
  определяются автоматически; если сервер присылает `Content-Disposition`,
  расширение уточняется.

## Шаблон имён

По умолчанию: `{artist}/{album}`.

Доступные поля:

| Поле | Значение |
|---|---|
| `{artist}` | исполнитель |
| `{album}` | название альбома (для трека — название трека) |
| `{title}` | название позиции |
| `{year}` | год покупки |
| `{purchased}` | дата покупки (`ДД.ММ.ГГГГ` по-русски, `ГГГГ-ММ-ДД` по-английски) |
| `{type}` | `album` или `track` |
| `{format}` | идентификатор формата (`flac`, `mp3-320`, …) |
| `{id}` | внутренний id покупки Bandcamp |
| `{key}` | ключ позиции в коллекции |

Символ `/` создаёт вложенные папки. Недопустимые для Windows символы
заменяются на `-`, зарезервированные имена (`CON`, `NUL`, …) экранируются.
Пример: `{artist}/{year} - {album}`.

## Настройки и файлы

Настройки сохраняются в:

* Windows: `%APPDATA%\BandcampCollectionDownloader\settings.json`
* macOS: `~/Library/Application Support/BandcampCollectionDownloader/`
* Linux: `~/.config/BandcampCollectionDownloader/`

Там же при необработанной ошибке создаётся `crash.log`.

Переменная окружения `BCD_CONFIG_DIR` позволяет указать другой каталог
настроек (удобно для тестов и портативного запуска).

Настройки содержат только параметры интерфейса и загрузки: профиль, формат,
папку, шаблон, потоки, прокси, язык и флажки. **Cookies туда не попадают.**

## Сборка Windows-исполняемого файла

Сборка создаёт **один портативный `.exe`**, внутри которого находятся Python,
Tkinter, Pillow, curl_cffi и все зависимости. На компьютере назначения Python
не нужен.

```bat
build.bat
```

Или вручную:

```bat
pip install -r requirements.txt -r requirements-build.txt
python -m PyInstaller --noconfirm --clean --onefile --windowed ^
  --name BandcampCollectionDownloader ^
  --icon assets\app.ico ^
  --version-file version_info.txt ^
  --hidden-import PIL._tkinter_finder ^
  --collect-all curl_cffi ^
  --collect-all browser_cookie3 ^
  --collect-data certifi ^
  --workpath build --distpath dist ^
  bandcamp_gui.py
```

Результат:

```text
dist\BandcampCollectionDownloader.exe
```

Первый запуск one-file сборки может занять несколько секунд: PyInstaller
распаковывает встроенную среду. Настройки по-прежнему хранятся в `%APPDATA%`,
поэтому сам EXE остаётся переносимым.

## Решение проблем

**«Нет активного входа в Bandcamp»**  
Войдите на bandcamp.com в браузере, выберите этот браузер в программе и снова
нажмите «Загрузить коллекцию». Либо вставьте cookies вручную через «Войти…».

**«Bandcamp вернул антибот-проверку» / «Client Challenge»**  
Установите `curl_cffi` (`pip install curl_cffi`), откройте bandcamp.com в
браузере, убедитесь, что вы вошли, и повторите. Помогает смена сети или
прокси.

**HTTP 429**  
Bandcamp ограничивает частоту запросов. Уменьшите число потоков до 2–4,
увеличьте паузу между попытками в «Дополнительно…» и повторите позже.
Программа уже делает повторы с нарастающей паузой.

**«Профиль не найден»**  
Проверьте имя: нужна часть после `bandcamp.com/`, без пробелов. Можно вставить
ссылку целиком — программа её разберёт.

**«Вы вошли как … а указан профиль …»**  
Используйте имя своего профиля, а не чужого: коллекция доступна только
владельцу аккаунта.

**Файл скачался не полностью**  
Оставьте `.part` на месте и запустите снова с включённым «Пропускать уже
скачанное»: докачка продолжится с места обрыва. Также можно увеличить число
попыток.

**Обложки не видны**  
Установите Pillow: `pip install Pillow`.

**Окно выглядит слишком крупным/мелким**  
Программа включает DPI-awareness Windows. Если масштаб всё равно неудобен,
измените масштаб в настройках дисплея Windows.

## Важно

* Скачивайте только тот контент, который вы купили.
* Не распространяйте полученные файлы: они предназначены для личного
  использования согласно условиям Bandcamp и правообладателей.
* Программа не обходит оплату, DRM и ограничения доступа. Она лишь
  автоматизирует штатное повторное скачивание покупок.
